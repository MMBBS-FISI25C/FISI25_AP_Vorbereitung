# Lernfeld 8 - Daten systemübergreifend bereitstellen
In diesem Kurs werden Sie viele Diagramme (z. B. ER-Modelle) zeichnen. Im Sinne einer Vorbereitung auf Abschlussprüfungen haben Sie bitte immer einen A4-Block und einen Kugelschreiber zur Hand. Damit fertigen Sie alle Diagramme zunächst als leserliche Handskizzen an. Wenn Sie Ihre Zeichnungen dann auch nochmal digitalisieren wollen, sind Programme wie LibreOffice Draw, Dia oder Draw.io empfehlenswert.
