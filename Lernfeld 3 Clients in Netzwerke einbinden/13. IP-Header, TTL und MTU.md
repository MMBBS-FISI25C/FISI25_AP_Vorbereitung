# 13. IP-Header, TTL und MTU

## IP-Header

Der IP-Header enthält alle Steuerinformationen, die ein Router benötigt, um das Paket weiterzuleiten.

### Alle wichtigen Felder

| Feld | Größe | Bedeutung |
|---|---|---|
| **Version** | 4 Bit | IP-Version: 4 für IPv4 |
| **IHL** (Internet Header Length) | 4 Bit | Länge des Headers als Vielfaches von 32 Bit; minimaler Wert: 5 × 32 Bit = **20 Byte** |
| **DSCP** (Differentiated Services) | 8 Bit | Bestimmt die Paketpriorität (Quality of Service) |
| **Total Length** | 16 Bit | Gesamtlänge des Pakets (Header + Daten) in Byte |
| **Identification** | 16 Bit | Eindeutige Nummer für Fragmentierung; alle Fragmente eines Pakets teilen dieselbe ID |
| **Flags** | 3 Bit | Steuerbits für Fragmentierung (siehe unten) |
| **Fragment Offset** | 13 Bit | Gibt an, ab welchem Byte innerhalb des ursprünglichen Pakets ein Fragment beginnt |
| **TTL** (Time To Live) | 8 Bit | Lebensdauer des Pakets; wird an jedem Router um 1 reduziert |
| **Protocol** | 8 Bit | Protokoll der nächsten Schicht (ICMP = 1, TCP = 6, UDP = 17) |
| **Header Checksum** | 16 Bit | Prüfsumme des Headers zur Fehlererkennung |
| **Quell-IP** | 32 Bit | IP-Adresse des Senders |
| **Ziel-IP** | 32 Bit | IP-Adresse des Empfängers |

---

## Flags im Detail

Die drei Flags steuern die Fragmentierung:

| Bit | Name | Bedeutung |
|---|---|---|
| Bit 0 | Reserviert | Muss immer 0 sein |
| Bit 1 | **DF** (Don't Fragment) | Wenn 1: Das Paket darf **nicht** fragmentiert werden |
| Bit 2 | **MF** (More Fragments) | Wenn 1: Es folgen **weitere Fragmente**; wenn 0: dies ist das **letzte Fragment** |

## TTL

TTL bedeutet:

```text
Time To Live
```

Die TTL verhindert, dass Pakete endlos im Netzwerk kreisen.

Jeder Router verringert die TTL um 1.

Wenn die TTL 0 erreicht:

```text
Das Paket wird verworfen.
```

---

## MTU

MTU bedeutet:

```text
Maximum Transmission Unit
```

Sie gibt an, wie groß ein Paket maximal sein darf, damit es über ein Medium übertragen werden kann.

Typischer Ethernet-Wert:

```text
1500 Byte
```

Wenn ein Paket größer als die MTU ist und das DF-Flag nicht gesetzt ist, wird es fragmentiert.
