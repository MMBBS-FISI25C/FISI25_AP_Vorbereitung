#### Strukturierte Programmierung, OOP und UML

##### Strukturierte Programmierung

> Lernziel: Programme mit den Grundbausteinen der strukturierten Programmierung entwerfen.

- **Grundprinzipien:** Sequenz, Selektion, Iteration (nach Böhm/Jacopini)
- **Top-Down- vs. Bottom-Up-Entwurf**
- **Modularisierung** (Funktionen / Prozeduren)
- **Kontrollstrukturen:**
  - Verzweigungen: `if`, `if-else`, `elif`, `match-case`
  - Schleifen: `while`, `for`, Schleifenabbruch (`break`, `continue`)
- **Variablen, Datentypen, Gültigkeitsbereiche (Scope)**
- **Parameterübergabe:** Call-by-Value vs. Call-by-Reference
- **Vermeidung von „Spaghetti-Code"** (kein `goto`)

##### Objektorientierte Programmierung (OOP)

> Lernziel: OOP-Konzepte verstehen und in Python anwenden.

- **Grundbegriffe:** Klasse, Objekt, Instanz, Attribut, Methode
- **Vier Säulen der OOP:**
  - **Kapselung** (Encapsulation) – `public`, `protected`, `private` (in Python: `_attr`, `__attr`)
  - **Vererbung** (Inheritance) – Einfach- und Mehrfachvererbung
  - **Polymorphie** – Methodenüberschreibung (Override), Überladung
  - **Abstraktion** – abstrakte Klassen, Interfaces
- **Konstruktor / Destruktor:** `__init__`, `__del__`
- **Klassenattribut vs. Instanzattribut**
- **Statische Methoden / Klassenmethoden:** `@staticmethod`, `@classmethod`
- **Beziehungen zwischen Klassen:** Assoziation, Aggregation, Komposition, Vererbung

##### UML (Unified Modeling Language)

> Lernziel: Software mithilfe von UML-Diagrammen modellieren und lesen.

- **Klassendiagramm** (wichtigstes Diagramm für die Klausur!)
  - Aufbau: Klassenname, Attribute, Methoden
  - Sichtbarkeiten: `+` public, `-` private, `#` protected, `~` package
  - Multiplizitäten: `1`, `0..1`, `*`, `1..*`
  - Beziehungen darstellen: Assoziation (Linie), Aggregation (leere Raute), Komposition (gefüllte Raute), Vererbung (Pfeil mit Dreieck), Realisierung (gestrichelt)
- **Anwendungsfalldiagramm (Use-Case-Diagramm):** Akteur, Use Case, `<<include>>`, `<<extend>>`
- **Aktivitätsdiagramm:** Start-/Endknoten, Aktion, Entscheidung, Synchronisation
- **Sequenzdiagramm:** Lebenslinie, Aktivierungsbalken, synchrone/asynchrone Nachrichten
- **Zustandsdiagramm** (optional, gelegentlich gefragt)

##### Klassen (OOP in Python)

```python
class Roboter:
    anzahl = 0  # Klassenattribut
    
    def __init__(self, name, akku=100):
        self.name = name          # Instanzattribut
        self.__akku = akku        # privates Attribut
        Roboter.anzahl += 1
    
    def fahren(self, strecke):
        self.__akku -= strecke
    
    def __str__(self):
        return f"Roboter {self.name}, Akku: {self.__akku}%"
```

- Vererbung: `class Schulungsroboter(Roboter):`
- `super().__init__(...)`
- Magic Methods: `__str__`, `__repr__`, `__eq__`, `__len__`
